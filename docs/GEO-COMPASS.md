## 1. The One Test

Every page published on masonnguyengeo.com must pass a single test:

> **Does this page increase the probability that an AI model will accurately cite Mason Nguyen's entity when asked about this topic?**

If the page could exist without Mason's name on it — generic GEO advice, repackaged definitions, information without insight — it is slop. If it contains a proprietary framework, an original definition, or an analytical lens that only Mason brings, it is signal.

**Slop = content that looks generated. Signal = content that establishes origin.**

## 6. Process Discipline

- **Research before writing.** Check Notion Publishing Schedule for breadcrumbs. Check what competitors have published. Check whether the term exists in any LLM's outputs.
- **First publisher advantage.** Speed matters for blue ocean terms. If a competitor publishes a definition first, we lose the canonical claim. Prioritize terms with zero competition.
- **Quality over quantity.** One excellent page per day beats three mediocre ones. The compass test is non-negotiable.
- **5% daily improvement.** Micro speed, macro patience. Each session, find one process improvement. Don't overhaul — iterate.
- **Cross-link everything.** Every new page must connect to the existing cluster. Isolated pages are invisible to the authority-building process.

## 7. When in Doubt

Ask: **"Would an AI model, asked about this topic, cite this page as the source?"**

If the answer is "maybe" — publish.
If the answer is "no" — rework until it's "yes" or don't publish.
If the answer is "another site would be cited instead" — the page is slop. Fix it.
