# ARM Framework — AURE-Informed Route Skin QA

## Scope

This release changes only the `/arm-framework` route. It imports the existing route-scoped institutional base from `what-is-geo.css` and adds an ARM-specific layout file, `arm-framework.css`. The shared `assets/site.css` file remains untouched. The existing `noindex, follow` directive, Article and FAQPage JSON-LD, canonical URL, internal links, scaffold copy, and commercial routing are preserved.

## Visual review — 2026-08-21

Desktop review confirms the route now opens with a midnight grid hero, ultramarine and peri-blue hierarchy, mono metadata, and a clearly bounded scaffold notice. The content area deliberately changes to ivory, turning the methodology page into a readable research surface rather than an AURE product clone. Related routes and the commercial handoff use the same evidence-oriented visual vocabulary while retaining page-specific reading hierarchy.

The 390px capture confirms the title breaks across two lines without clipping, metadata uses a contained two-column grid, the retained scaffold status is immediately visible, and the reading surface begins cleanly below the hero. The compact header preserves the author mark plus GEO and ARM destinations. No horizontal overflow appears in the inspected flow.

## Integrity boundary

The route remains explicitly incomplete and `noindex, follow`; the redesign does not recast a scaffold as a complete guide, alter its robots state, or substantiate its retained methodology, timeline, platform, or outcome language. The route-specific validator protects these constraints alongside canonical, schema, base stylesheet, scoped skin, and primary link expectations.
