# Intelligence Infrastructure and Sitemap — AURE-Informed Route QA

## Scope

This release changes only `/intelligence-infrastructure` and `/sitemap`. Both routes load the existing body-scoped AURE-inspired base plus their own route stylesheet after `assets/site.css`; the shared legacy stylesheet remains unchanged. The Intelligence Infrastructure route retains its canonical URL, existing Article and BreadcrumbList schema, `noindex, follow` directive, related links, and explicit scaffold status. The sitemap retains its canonical URL, WebPage schema, all named route categories, every route destination, and all machine-readable file entries.

## Desktop review — 2026-08-21

The Intelligence Infrastructure route replaces the legacy gold-on-black composition with a midnight infrastructure grid, ultramarine/peri-blue hierarchy, bounded scaffold notice, and ivory reading surface. It now reads as an AURE-adjacent research route without presenting a scaffold as a completed guide.

The sitemap now functions as a deliberate discovery directory: a midnight index header frames a series of ivory category panels, while two-column route cards preserve every visible destination and machine-readable file entry. This turns navigation into an inspectable, readable system rather than a legacy text list, without altering the site’s information architecture.

## Mobile review — 2026-08-21

The 390px Intelligence Infrastructure view retains a compact author mark with GEO and ARM navigation, wraps the long route name and title without clipping, converts metadata to an orderly two-column arrangement, and keeps the scaffold boundary immediately visible. The first reading sections begin cleanly on an ivory field, with no horizontal overflow in the inspected flow.

The 390px sitemap view preserves the system-header hierarchy and moves each category to a one-column route directory. Long labels wrap inside their cards, the route number remains visually distinct, and every visible category remains separated on the midnight grid. No horizontal overflow appears in the inspected mobile capture.
