# Applied Systems: Site Placement Recommendation

## Short answer

Yes. The apps belong on the site as an **Applied Systems** layer: the research explains the model, while selected public builds show the model being practiced. This should not look like a startup portfolio or a directory of every Base experiment. It should be a small, carefully bounded evidence layer.

## Homepage section: recommended composition

The first homepage version should use three compact cards, not all fourteen apps. Its job is to create a link between the method and the systems without asking visitors to interpret an unfiltered experimental archive.

> **04 / Applied systems**
>
> **Research becomes useful when it leaves a record.**
>
> Selected public builds and working prototypes that make Mason Nguyen’s systems practice inspectable. Each record names its current phase and its claim boundary.

The cards should feature **Cite Watch Pulse**, **Arctura Base Subnet**, and **Atlas Nexus GEO**. Stack Your Papers should live on the dedicated page and on the ARM Framework route rather than the homepage, since its public screen is an internal database shape rather than a broadly legible product surface.

## Important boundary

The app links should not import every claim displayed on the external Base pages into masonnguyengeo.com. The site should describe only the build’s visible purpose and current phase. For example, `Cite Watch Pulse` is a measurement interface, not a citation-performance result while it shows zero completed sweeps. `Atlas Nexus GEO` is a systems-map prototype, not a validated results report. The Base subnet should remain explicitly in its stated protocol-build phase unless the source record supports a later status.

## Minimal first implementation

Build the homepage section and the `/applied-systems` page with the three initial cards. Add the link to the human Site Index and footer. Leave the broader experiments archive for a later release after authentication-gated apps have short public walkthroughs and the externally facing claims have been reviewed.
