01 / Why a build record

Research becomes useful when it leaves a record.

The research pages explain the method. The systems here show the artifacts that method produces. Each record is intentionally small: a visible build, a stated role, a current phase, and a boundary around what the artifact can and cannot evidence.

This distinction matters for GEO. A dashboard is not a result. A protocol concept is not a deployed network. A systems map is not a performance study. By keeping those categories separate, the site can show applied work without converting every interface into an unsupported claim.

03 / Record standard

Every artifact has to state what can be inspected.

04 / Operating order

Build, document, observe, then revise.

1

Give the system a real public role.

State the decision, research question, or workflow the artifact supports. Avoid language that treats a branded interface as proof of market adoption.

2

Link the artifact and its source path.

Make the build inspectable through a public route, repository, documentation record, or dated method note where the relevant evidence can be reviewed.

3

Record what was observed.

When a build produces an observation, retain the query, settings, date, output, and uncertainty. Keep an observed result separate from a causal explanation.

4

Maintain the phase label.

Update or remove records when their public state changes. A clear Phase 0 prototype is more credible than a stale page implying it has become something else.

05 / Research connections

The artifact should strengthen a source, not replace it.

The GEO Stack explains the public source layers that make a record legible. Cite Watch Pulse turns a limited portion of that question into an observation surface. The ARM Framework provides a method boundary for decisions, retrieval, and responsible action. The Base subnet record names a current Bittensor-facing protocol interest without claiming that the research site itself is an operator or platform.

Future records will be added only when a public artifact has a defined role, a useful evidence path, and a statement of current phase. That standard is part of the work.
