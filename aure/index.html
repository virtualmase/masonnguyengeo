01 / Definition

Working premise

An agent should be able to stand up to inspection.

An agent should be more than a persuasive interface. It should have a clear job, inspectable evidence, known limits, and an accountable owner who can explain what happened when the work is wrong.

AURE begins with a practical question: can a reviewer understand what an agent was asked to do, what it was allowed to access, what evidence shaped its output, where its tool use broke down, and how a responsible person corrected it?

Working definition

AURE is Swell Marketing's forensic agent review method. It combines AI agent evaluation, testing, trace review, and accountable human oversight to improve real workflows.

02 / Forensic review

Reconstruct the work before you repair it.

A useful review is not a vanity score or a theatrical audit performed from a distance. It is a disciplined reconstruction of an agent in context.

  1. 01

    Reconstruct the assignment.

    Identify the agent's job, instructions, interfaces, data sources, permissions, handoffs, and expected decision boundary.

  2. 02

    Trace the record.

    Follow a defined set of real or representative tasks through the available prompts, retrieved material, tool actions, outputs, and reviewer interventions.

  3. 03

    Challenge assumptions.

    Test unclear instructions, weak evidence, missing context, conflicting sources, and situations where a tool call or confident answer would create avoidable harm.

  4. 04

    Write the finding.

    Separate observed behavior from interpretation. Name the evidence, risk, owner, repair, and unresolved uncertainty.

  5. 05

    Re-review the change.

    Check the correction against the same questions so a team can distinguish an actual improvement from a better-looking demonstration.

03

Building agents

Real value comes from the system around the agent.

Agents can help with research, triage, drafting, source comparison, operational handoffs, and other bounded work. But an agent becomes useful only when it has the right context, usable tools, a reviewable record, and a human decision-maker who understands what should never be delegated.

With the help of its own agents, Swell has developed an in-house review method for examining agent behavior and improving the systems around it. The method is proprietary. The public principle is simple: claims about an agent should be matched to evidence a reviewer can inspect.

What a review is not

It does not certify an agent.

A review does not certify an agent as safe, accurate, compliant, or universally fit for purpose. It does not replace domain expertise, legal review, security review, or accountable operational ownership.

Method scope

AURE belongs in the applied work.

AURE is Swell Marketing's method for agent reviews, practical remediation, release control, and learning resources that help teams turn findings into better operating practice. Mason Nguyen's research can link to the work, but Swell is where the method is applied and improved.

It makes the current system easier to inspect and improve.
